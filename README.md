# PodPilot

Zie de batterij van je AirPods op je Windows-pc en verbind ze met één klik.

[![Download PodPilot voor Windows](https://img.shields.io/badge/Download-PodPilot%20voor%20Windows-2F7DF6?style=for-the-badge&logo=windows&logoColor=white)](https://github.com/stefvanotterlo/PodPilot/releases/latest/download/PodPilot-Setup.exe)

## Installeren

1. Klik op de knop hierboven om **PodPilot-Setup.exe** te downloaden.
2. Open het bestand. Waarschuwt Windows ("Windows heeft uw pc beveiligd"), klik dan op
   **Meer info** › **Toch uitvoeren**.
3. Volg de stappen. PodPilot verschijnt daarna als icoontje rechtsonder bij de klok.

Je AirPods moeten al met de pc gekoppeld zijn via de Bluetooth-instellingen van Windows.

## Wat kan het?

- Batterij van links, rechts en de case, ook als je de case opent
- Verbinden en verbreken met één klik, of automatisch
- Muziek pauzeren als je een oordop uitdoet
- Melding als de batterij bijna leeg is

Werkt op Windows 10 en 11. Geen account of internet nodig.
